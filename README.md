# Static Storage

個人靜態資源託管中心，主要用於 CDN 加速分發。

## 📁 目錄說明
- `/audio` - 背景音樂及音效
- `/images` - 網頁配圖、Logo、個人素材
- `/video` - 短影片及動態背景素材

## 🔗 引用公式 (jsDelivr)
將下面的 `[用戶名]` 替換為你的 GitHub ID 即可：

**通用格式：**
https://cdn.jsdelivr.net/gh/[用戶名]/static@main/路徑/檔案名

**範例：**
https://cdn.jsdelivr.net/gh/[用戶名]/static@main/audio/test.mp3

## 📝 注意事項
- 請務必使用 **全小寫** 命名檔案和資料夾。
- 檔案名中 **不要包含空格**（建議使用 `-` 代替）。
- 這是一個 Public 倉庫，請勿上傳包含個人隱私的檔案。
